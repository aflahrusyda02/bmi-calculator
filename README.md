BMI Checker

Fitur
- Input berat badan dan tinggi badan lewat slider
- Hasil BMI diperbarui langsung saat slider digeser
- Kategori BMI dengan warna dan progress bar
- Menampilkan rentang berat ideal sesuai tinggi badan

Kategori BMI :
| BMI | Kategori |
|-----|----------|
| < 18,5 | Berat badan kurang |
| 18,5 - 24,9 | Normal |
| 25 - 29,9 | Berlebih |
| >= 30 | Obesitas |

Cara menjalankan
1. Pastikan JDK dan library JavaFX sudah terpasang
2. Buka project di NetBeans
3. Jalankan file bmiCalculator.java
